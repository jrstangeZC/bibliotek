# Interface copy is Norwegian

All text the user sees in the interface is written in Norwegian (bokmål). This
covers headings, body copy, button and link labels, form labels, placeholders,
descriptions, error and empty-state messages, badges, `aria-label`, `title` and
`alt` attributes, and page metadata.

- Use Norwegian sentence case: «Lån ut», not «Lån Ut».
- Use « » for quotes and a space as the thousands separator (`1 248`).
- Code stays in English: identifiers, comments, prop names and type names.
